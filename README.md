I work on efficient and reliable large language models: token-efficient inference, long-context evaluation, KV-cache compression, retrieval, and agentic workflows.

Currently I am a Ph.D. student at HKUST(GZ), supervised by Prof. Xiaowen Chu and Prof. Xuming Hu, and a research intern at Mind Lab working on post-training and agent harnesses.

### What I Build

| Direction | Representative work |
| --- | --- |
| Long-context evaluation | [LongGenBench](https://github.com/Dominic789654/LongGenBench), generation-focused benchmark for long-context LLMs |
| Inference efficiency | ChunkKV, Semantic Integrity Matters, FlowKV, energy-to-token evaluation |
| Agent evaluation | [QuantArena](https://github.com/Dominic789654/quantarena-clean), policy-conditioned live-market evaluation for LLM trading agents |
| Agent infrastructure | [agent-hub](https://github.com/Dominic789654/agent-hub), local-first queueing and dispatch for coding/research agents |
| Tool-use compatibility | [tinker2openai-tool](https://github.com/Dominic789654/tinker2openai-tool), adapters between XML-like tool calls and OpenAI-style tool calls |
| Research workflow | [MyArxiv](https://github.com/Dominic789654/MyArxiv), [scholar_tracker](https://github.com/Dominic789654/scholar_tracker), [scientific-figure](https://github.com/Dominic789654/scientific-figure) |

### Research Threads

- KV-cache compression that preserves semantic structure under long-context inference.
- Evaluation beyond retrieval: generation quality, dense reasoning, multi-turn coherence, and agentic behavior.
- Post-training and serving systems for tool use, code generation, and long-horizon agent workflows.
- Practical research infrastructure: benchmarks, reproducible artifacts, trackers, and paper/project pages.
